A7.
A webpage can contain different information on different layout according to its width height etc..
On a mobile which is a less width device, normally less wide content is used means the layout is set to minimal
On a desktop window the screen has a vast width which allows us to design big layouts

On desktop first it is trimmed down for mobile compatibility where an already added content or layout is stripped down to its making a lot of styles overriden when the media queries works
So attempting mobile first means building something smaller and adding bigger layouts adding columns and contents for desktop, in this approach a lot of styles are added than overriden

.grid-container {
    grid-template-columns: 1fr;
}
@media (min-width:800px){
    .grid-container {
        grid-template-columns: repeat(2,1fr);
    }
}
@media (min-width:1440px){
    .grid-container {
        grid-template-columns: repeat(3,1fr);
    }
}


A8.
rem for a structured page, where all the typography matters, rem is relative to the base font-size of the html element
px when the viewport has a fixed dimension, example a device with 480px * 780px etc.. where the pixel distance of width and height is fixed.
% when it is needed to be adjusted according to the parent element

When someone tries ti increase the browsers default font size, if the type scale is hardcoded in px the font size will not increase, because the fonts are sized in terms of pixels, they will not increase like a pixel on the screen cannot be increased in size
